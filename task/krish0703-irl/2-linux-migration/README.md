# Linux Migration

## Approach

I completed the Linux Migration task using **WSL2** instead of dual boot.

I installed **Ubuntu 24.04.4 LTS** through WSL2 on Windows and configured the Linux environment successfully.

## Verification

The Linux environment was verified using basic terminal commands, including:

```bash
pwd
whoami
uname -a
cat /etc/os-release
```

I also installed and ran `neofetch` to verify the Linux environment and system information.

## Evidence

The `neofetch-screenshot.png` file contains the required screenshot of `neofetch` running in the Ubuntu Linux terminal.

The screenshot shows:

- Ubuntu 24.04.4 LTS
- WSL2 kernel
- Bash shell
- CPU and memory information

## Result

Linux was successfully installed and configured using WSL2, and the environment was verified successfully.
