# Task 3 — Algorithm Tour

## Overview
This task demonstrates the implementation of fundamental searching and sorting algorithms in Python:
- **Binary Search**
- **Merge Sort**

---

## Algorithms Summary

### 1. Binary Search
- **Description:** Efficiently finds the index of a target element in a sorted list by repeatedly dividing the search interval in half.
- **Time Complexity:** O(log n)
- **Space Complexity:** O(1)

### 2. Merge Sort
- **Description:** A divide-and-conquer sorting algorithm that splits an array into halves, recursively sorts them, and merges the sorted halves.
- **Time Complexity:** O(n log n)
- **Space Complexity:** O(n)
